# RWMLWC — мультиплеер для RimWorld 1.7

Мод кооперативной игры для RimWorld 1.7 (движок Waylith, .NET 10, Harmony 3).

Цели:

- начать в одном поселении и разойтись в разные, торговать и ходить в гости;
- кнопкой переключиться на поселение друга и с его разрешения управлять пешками и стройкой;
- работать с большим числом модов без патча под каждый.

## Правовые ограничения

- Код RimWorld Together (CC BY-NC-ND 4.0) и Multiplayer (rwmt) не копируем. Смотреть подходы можно, переносить код нельзя.
- `Assembly-CSharp.dll`, `Waylith.dll` и другие файлы игры в репозиторий не кладём.
