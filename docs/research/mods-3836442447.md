## Готовая совместимость, которую можно использовать

Multiplayer Compatibility (лицензия MIT) упоминает 25 модов с кодом из этой сборки. Среди них VEF, VPE, VFE Empire, VIE Memes, VTE, VSE, HAR, Fortified, RimDark, DMS и Expedition, Sparkling Worlds, Alpha Animals, Dubs Mint, Utility Columns и Nice Plants Menu.

YART и Fortified сами поставляют `0MultiplayerAPI.dll`: они объявляют свои действия через интерфейс Multiplayer API.

Отсюда главное решение по объёму: вместо того чтобы вписывать действия каждого мода в `MethodCommands`, можно **реализовать интерфейс Multiplayer API поверх нашей шины команд**. Тогда описания из Multiplayer Compatibility и из самих модов заработают в RWMLWC без переписывания.

Это крупная работа. Нужно реализовать:
- синхронизацию методов, полей и замыканий;
- сериализаторы своих типов;
- окна-диалоги.

Сначала нужно проверить, что наш `ValueCodec` и `MethodCommands` это покрывают. Это предположение: интерфейс API не разобран декомпиляцией.
