# Сетевая игра: два способа

Игрок сам выбирает, как играть по сети. Оба способа работают одинаково для игры: общие часы, общий порядок команд, сверка хешей.

| | P2P — сессия в игре хоста | Выделенный сервер (необязательно) |
|---|---|---|
| Как запустить | В игре: «Сетевая игра» → «Создать игру», или в меню паузы «Открыть сессию для друзей» | Программа `RWMLWC.Server` на любом компьютере с Windows 11 / Server 2022 |
| Как подключиться | Steam: SteamID или «Присоединиться» в списке друзей. По желанию — прямой код (`direct_port` в `host.txt`) | Код подключения `rwmlwc://адрес:порт/…` из консоли сервера |
| Проброс портов | Не нужен (Steam). Для прямого кода через интернет — нужен | Нужен для игры через интернет (UDP) |
| Когда хост вышел | Сессия закрывается | Сервер работает дальше; мир хранится на сервере |
| Настройки | `<данные игры>\RWMLWC\host.txt` | `<папка сервера>\server.txt` |

## Файлы настроек

Оба файла создаются сами при первом запуске, с комментариями. Формат — строки `ключ = значение`, `#` — комментарий. Изменения действуют при следующем запуске сервера или открытии сессии.

**`server.txt`** (выделенный сервер):

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `port` | 47800 | Порт UDP (QUIC). Для игры через интернет пробросьте его на роутере. 0 — любой свободный |
| `public_host` | пусто | Внешний адрес: сервер напечатает готовый код для интернета |
| `autosave_minutes` | 5 | Автосохранение мира на сервер, минут; 0 — выключено |
| `max_players` | 8 | Игроков одновременно |
| `max_lead_ticks` | 180 | На сколько тиков часы сервера могут опережать самого медленного игрока. Меньше — быстрее исполняются приказы, входят новички и лечится расхождение; больше — медленный компьютер реже притормаживает остальных. 0 — без ограничения |
| `keep_copies` | 5 | Сколько последних копий мира хранить в `saves/` |
| `backup_hours` | 24 | Раз в сколько часов класть копию мира в `backups/`; 0 — не делать |
| `keep_backups` | 7 | Сколько резервных копий хранить |
| `whitelist` | пусто | Имена игроков через запятую (регистр не важен); пусто — пускать всех. Имя игрок задаёт сам, так что это защита от случайных людей, а не пароль |
| `password` | пусто | Пароль сервера; игроки вводят его в окне «Подключиться к серверу». Пусто — без пароля |
| `alarm_seconds` | 45 | Тревога: крупная угроза на карте отошедшего игрока ставит игру у всех на паузу на столько секунд (или пока он не вернётся) |

Аргументы командной строки `--port`, `--public-host` важнее файла.

**`host.txt`** (сессия в игре хоста):

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `direct_port` | 0 | 0 — друзья входят только через Steam. Число — хост ещё и принимает прямые подключения по коду на этом порту (код — в окне «Игроки и чат», кнопка «Копировать») |
| `max_players` | 8 | Игроков одновременно |
| `max_lead_ticks` | 180 | Как в `server.txt` |
| `password` | пусто | Пароль сессии: друзья вводят его в окне подключения (Steam и по коду) |
| `alarm_seconds` | 45 | Как в `server.txt` |

## Выделенный сервер

**Готовая сборка:** GitHub → Actions → последний прогон CI на `main` → Artifacts → `rwmlwc-server-win-x64` (или `rwmlwc-server-linux-x64`). Это папка с программой, .NET ставить не нужно. Запуск: `RWMLWC.Server.exe --data D:\rwmlwc-server`. На Linux ещё нужна библиотека `libmsquic`.

Из исходников:
```
dotnet RWMLWC.Server.dll --data D:\rwmlwc-server
```

`--data` — папка сервера: `server.txt`, сертификат (`server.pfx`) и копии мира (`saves/`, хранятся последние 5). Сертификат создаётся при первом запуске. От него зависит код подключения, поэтому папку не удаляйте.

Код подключения: в игре «Сетевая игра» → «Подключиться к серверу». Если код уже скопирован, окно подставит его само. Отпечаток в коде защищает от подмены: игра примет только этот сервер.

### Откуда берётся мир

- **Сервер пуст, копии нет.** Первым входит игрок со своим сейвом, и его мир становится миром сервера. Игроку без сейва сервер откажет и объяснит причину.
- **Сервер пуст, копия есть.** Игрок без сейва получает мир от сервера. Игрок с более новым сейвом того же мира играет своим. Более старый сейв или сейв другого мира заменяется миром сервера.
- **В сети уже играют.** Новичку мир отдаёт игрок, у которого **лучший пинг до сервера**. Сервер знает пинг каждого игрока до себя, а не между игроками; путь «отдающий → сервер → новичок» короче всего через того, кто ближе к серверу.
- **Автосохранение.** Каждые `autosave_minutes` и когда кто-то выходит, сервер просит игрока с лучшим пингом прислать мир и сохраняет копию. Игра при этом не останавливается и ни у кого не перезагружается. Если все вышли, следующий вход начнётся с последней копии.
- **Расхождение.** Если состояния игроков разошлись, сервер сам заказывает общий снимок, и все его загружают. Отдающий выбирается из **большинства**: сервер до 2 с ждёт хеши всех игроков за этот тик, и мир берётся у того, чей хеш совпал с большинством (среди них — лучший пинг). При двух игроках большинства нет — лучший пинг среди обоих.

### Команды консоли

| Команда | Что делает |
|---|---|
| `status` | тик, скорость, сколько игроков в сети, последняя копия мира |
| `players` | игроки: номер, имя, в сети ли, пинг |
| `say текст` | сообщение в чат от «Сервера» |
| `kick номер` | отключить игрока (номер и права сохраняются, он может вернуться) |
| `saves` | копии мира на диске |
| `stop` | остановить сервер |

Пустой сервер не тикает: когда в сети никого нет, часы стоят.

## Запуск без присмотра

**Не проверено** — описано по документации .NET.

**Linux** (x64 или ARM64): нужен .NET 10 Runtime и библиотека QUIC `libmsquic` (Ubuntu/Debian: пакет `libmsquic` из репозитория Microsoft).
```
dotnet RWMLWC.Server.dll --data /srv/rwmlwc
```
Как служба systemd (`/etc/systemd/system/rwmlwc.service`):
```
[Unit]
Description=RWMLWC server
After=network-online.target

[Service]
WorkingDirectory=/srv/rwmlwc
ExecStart=/usr/bin/dotnet /opt/rwmlwc/RWMLWC.Server.dll --data /srv/rwmlwc
Restart=on-failure
StandardInput=null

[Install]
WantedBy=multi-user.target
```
Без консоли (`StandardInput=null`) команды недоступны: сервер просто работает. Остановка — `systemctl stop rwmlwc`.

**Windows без окна:** «Планировщик заданий» → задача «при запуске компьютера» → программа `dotnet`, аргументы `"C:\rwmlwc\RWMLWC.Server.dll" --data "C:\rwmlwc-data"`. Как настоящая служба Windows сервер пока не умеет.

**Обновление мода и сервера:** остановить сервер (`stop`), заменить файлы программы, запустить снова. Мир лежит в папке `--data` и сохраняется. Клиенты и сервер должны быть одной версии протокола: сервер отказывает другим версиям и пишет причину.
