# Выделенный сервер (T-058)

Сервер — консольная программа `RWMLWC.Server` (.NET 10). Игру он не считает: хранит копии мира, ведёт общие часы и упорядочивает команды игроков.

## Запуск

```
dotnet RWMLWC.Server.dll --data D:\rwmlwc-server [--port 47800] [--public-host мой.адрес.или.IP]
```

- `--data` — папка сервера: сертификат (`server.pfx`) и копии мира (`saves/`, хранятся последние 5). Сертификат создаётся при первом запуске, и от него зависит код подключения, поэтому папку не удаляйте.
- `--port` — порт UDP (QUIC), по умолчанию 47800. Для игры через интернет пробросьте его на роутере.
- `--public-host` — внешний адрес. Если он указан, сервер напечатает готовый код для игры через интернет.

Сервер печатает **код подключения** вида `rwmlwc://адрес:порт/отпечаток`. В игре: «Сетевая игра» → «Подключиться к серверу» → вставить код. Если код уже скопирован, окно подставит его само. Отпечаток защищает от подмены: игра примет только этот сервер.

Нужна Windows 11 или Windows Server 2022 и новее (QUIC).

## Откуда берётся мир

- **Сервер пуст, копии мира нет.** Первым должен войти игрок с загруженным сейвом. Его мир становится миром сервера. Игрока без сейва сервер не пустит и объяснит причину.
- **Сервер пуст, копия есть.** Игрок без сейва получает мир от сервера. Игрок с сейвом того же мира, который **новее** копии, играет своим сейвом. Сейв старше копии или другого мира заменяется миром сервера.
- **В сети уже кто-то есть.** Новичок получает мир от игрока, который в игре. Сейчас это работает, только если этот игрок — хост сессии в игре. На выделенном сервере назначить «отдающего» пока нельзя: нужна доработка клиента (КОНТРАКТ v4, запись B в `log/B.md`).
- **Копия мира** сохраняется, когда мир передаётся новичку или при лечении расхождения. Регулярного автосохранения пока нет — тоже КОНТРАКТ v4. Если все вышли, следующий вход начнётся с последней копии: прогресс после неё будет потерян.

## Команды консоли

| Команда | Что делает |
|---|---|
| `status` | тик, скорость, сколько игроков в сети, последняя копия мира |
| `players` | игроки: номер, имя, в сети ли, пинг |
| `say текст` | сообщение в чат от «Сервера» |
| `kick номер` | отключить игрока (номер и права сохраняются, он может вернуться) |
| `saves` | копии мира на диске |
| `stop` | остановить сервер |
